BigLineColoring Pins – Privacy Policy

Last updated: September 30, 2026

BigLineColoring Pins is a private tool used only by the owner of the BigLineColoring Etsy shop (etsy.com/shop/BigLineColoring). It is not offered to other people.

What it does

It publishes pins about the shop's own printable coloring books to the shop owner's own Pinterest account, and reads that account's own boards so it can post pins to the right board.

What data it uses

It uses only the shop owner's Pinterest login token, which is stored encrypted and privately and is never shared. It does not collect, read or store any information about other Pinterest users, and it does not use data for advertising.

Removing access

The owner can revoke the app's access at any time in Pinterest settings (Security and logins → Apps).

Contact

Questions: message BigLineColoring through Etsy at etsy.com/shop/BigLineColoring.
